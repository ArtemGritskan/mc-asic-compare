# Mining Cluster — Сравнение ASIC

Инструкция для установки плагина на WordPress и подключения товаров магазина.
Версия: 1.1.1.

## 1. Что делает плагин

Добавляет на страницу сравнение ASIC по цене, хешрейту, потреблению и наличию. Посетитель нажимает «Добавить устройство», находит модель по названию и выбирает до трёх устройств. Добавление и удаление выполняются прямо на сайте, без входа в админку. При открытии выбраны первые две доступные модели; если в каталоге только одна, выбирается одна.

Источник данных — товары WooCommerce на том же сайте. Плагин не копирует товары с cluster-mining.com и не синхронизирует разные сайты. Доходность не рассчитывается.

## 2. Требования и установка

Нужны WordPress, активный WooCommerce и PHP 7.4 или новее. Посетителю нужен современный браузер с включённым JavaScript. REST API WordPress должен быть доступен для чтения без авторизации.

1. Откройте «Плагины → Добавить плагин → Загрузить плагин».
2. Выберите архив `mc-asic-compare-1.1.1.zip` и нажмите «Установить».
3. Активируйте «Mining Cluster — Сравнение ASIC».
4. Создайте тестовую страницу через «Страницы → Добавить новую».
5. Добавьте блок «Шорткод» и вставьте:

   ```text
   [mc_asic_compare]
   ```

6. Опубликуйте страницу и откройте её как обычный посетитель.

Если используется Elementor, вставьте этот же текст в виджет «Шорткод». Для удобного сравнения выберите широкую область содержимого страницы.

В архив входят только файлы плагина. Товары, фото, настройки локального сайта и тестовая страница в архив не входят. На новом сайте страницу нужно создать самостоятельно. Плагин работает независимо от калькулятора размещения `mc-tools`; устанавливать его не требуется.

## 3. Как подключить карточки товаров

Отдельно добавлять каждый товар в настройки сравнения не нужно. Подходящие опубликованные товары автоматически появляются в окне выбора.

### Пример подключения простого товара

1. Откройте «Товары → Добавить новый» или отредактируйте существующий товар.
2. Укажите название модели и основное изображение товара.
3. В блоке «Данные товара» выберите «Простой товар».
4. На вкладке «Основные» укажите цену. Если действует скидка, сравнение использует текущую цену WooCommerce.
5. На вкладке «Запасы» настройте наличие.
6. На вкладке «Атрибуты» добавьте значения из таблицы ниже и сохраните атрибуты.
7. Опубликуйте или обновите товар. Обновите страницу сравнения и найдите модель по названию.

| Атрибут | Пример значения | Обязательность |
| --- | --- | --- |
| Алгоритм | `SHA-256` | Обязательно: определяет попадание товара в сравнение |
| Хешрейт | `235 TH/s` | Можно оставить пустым |
| Потребление | `3500 Вт` | Можно оставить пустым |

Название «Хэшрейт» также поддерживается. Единицы измерения записывайте прямо в значение атрибута. Характеристики берутся из атрибутов, а не из названия, описания товара или произвольных полей ACF. Автоматического пересчёта единиц нет: для удобного сравнения используйте единый формат, например TH/s и Вт.

Товар должен быть опубликован и не защищён паролем. Черновики не показываются. Скрытые из каталога товары исключаются, кроме товаров, явно указанных в приоритетном списке в настройках плагина. Отсутствие товара на складе не исключает его из сравнения.

### Если атрибуты уже созданы в вашем магазине

Плагин распознаёт следующие имена:

| Характеристика | Поддерживаемые имена / системные ключи |
| --- | --- |
| Алгоритм | `Алгоритм`, `pa_algorythm`, `pa_algorithm` |
| Хешрейт | `Хешрейт`, `Хэшрейт`, `pa_heshrejt`, `pa_hashrate` |
| Потребление | `Потребление`, `pa_energy-consump`, `pa_power` |

Для глобального атрибута WooCommerce используется ключ `pa_` плюс его slug. Например, для slug `hashrate` это `pa_hashrate`.

Если магазин использует другие названия, разработчик должен добавить их в соответствующий массив `attributes` файла `config/catalog.php`. Например, ключ `pa_power-consumption` нужно добавить в массив `power`. Значения карточек при этом остаются в WooCommerce — переносить их в PHP не нужно.

### Вариативные товары

В сравнение попадают отдельные опубликованные вариации, а не родительский товар целиком. Так цена относится к конкретному исполнению устройства.

Каждая вариация должна иметь определённые характеристики. Общий алгоритм, хешрейт или потребление могут наследоваться от родителя, только если соответствующий атрибут не используется для вариаций и содержит одно значение. Если характеристика различается между вариациями, задайте её для конкретной вариации. Для приоритетного списка используйте ID вариации.

## 4. Какие устройства выбраны при открытии

Настройки нужны только владельцу сайта для начального порядка моделей. Посетитель выбирает устройства самостоятельно на странице.

1. Откройте «Настройки → Сравнение ASIC».
2. Укажите до пяти ID товаров или конкретных вариаций в желаемом порядке.
3. Нажмите «Сохранить изменения».

ID простого товара виден в разделе «Товары → Все товары» при наведении на его название. ID вариации можно посмотреть на вкладке «Вариации» внутри родительского товара.

Первые две подходящие модели будут выбраны по умолчанию. Остальные товары каталога также доступны посетителю: пять полей не ограничивают общее число устройств. После приоритетных позиций остальные идут по названию.

Если настройки ещё ни разу не сохранялись, плагин сначала ищет пять исходных моделей по slug из `config/catalog.php`. Если таких товаров нет, используются доступные товары каталога. Сохранённый пустой список отключает этот исходный приоритет, но не скрывает каталог.

## 5. Цена, наличие и отсутствующие значения

| Данные карточки | Что увидит посетитель |
| --- | --- |
| Цена не заполнена | «Цена по запросу» |
| Цена равна нулю | Нулевая цена, а не «Цена по запросу» |
| Хешрейт или потребление не заполнены | «Не указано» |
| Товар в наличии | «В наличии» |
| Товара нет на складе | «Нет в наличии» |
| WooCommerce сообщает заказ с ожиданием | «Под заказ» |
| Наличие неизвестно | «Наличие уточняется» |
| Нет фото | Заглушка ASIC |

В карточке товара на вкладке «Запасы» плагин добавляет:

- **«Наличие в сравнении»**: стандартное наличие WooCommerce, «Предзаказ» или «Наличие уточняется».
- **«Цена „от“ в сравнении»**: добавляет «от» перед ценой. Это подпись, она не рассчитывает минимальную цену других моделей или вариаций.

Эти дополнительные поля интерфейса сохраняются у редактируемого товара. Для отдельных вариаций собственного редактора таких полей в этой версии нет: по умолчанию используются цена и складские данные вариации. Если разработчику нужны дополнительные статусы именно для вариации, метаданные нужно задавать на её ID, а не на родителе.

Валюта, число десятичных знаков и режим отображения налогов определяются настройками WooCommerce. Измените данные в карточке и обновите страницу сравнения — новые значения загрузятся. Уже открытая вкладка автоматически не опрашивает магазин.

## 6. За что отвечает каждый файл

```text
mc-asic-compare/
├── mc-asic-compare.php
├── README.md
├── uninstall.php
├── config/
│   └── catalog.php
├── includes/
│   ├── admin.php
│   ├── products.php
│   └── shortcode.php
└── assets/
    ├── compare.css
    └── compare.js
```

| Файл | Назначение | Когда менять |
| --- | --- | --- |
| `mc-asic-compare.php` | Главный файл: описание и версия плагина, подключение PHP-модулей, регистрация REST-маршрута. Добавляет noindex страницам с меткой `_mcac_test_page=yes`. | Изменение версии, подключения модулей или API. Обычная установка правок не требует. |
| `includes/products.php` | Получает товары и вариации WooCommerce, проверяет публикацию, алгоритм и видимость, собирает цену, наличие, фото и характеристики. | Изменение правил отбора товаров или источника данных. |
| `includes/admin.php` | Экран приоритетных моделей в настройках WordPress; дополнительные поля наличия и цены «от» в карточке товара; проверка и сохранение настроек. | Изменение административных настроек и полей товара. |
| `includes/shortcode.php` | Регистрирует `[mc_asic_compare]`, выводит HTML блока и окна выбора, подключает CSS и JavaScript только при выводе шорткода. | Изменение заголовков, подписей и разметки. |
| `config/catalog.php` | Хранит исходные slug пяти моделей и поддерживаемые имена атрибутов. Цены и характеристики здесь не хранятся. | Подключение существующих атрибутов с другими именами; изменение исходного приоритета. |
| `assets/compare.js` | Загружает данные, выбирает первые две модели, управляет поиском, окном выбора, добавлением, удалением и лимитом в три устройства. | Изменение поведения посетительского интерфейса. |
| `assets/compare.css` | Внешний вид карточек, таблицы, кнопок и окна выбора, адаптация под телефон. | Изменение цветов, отступов, шрифтов и расположения элементов. |
| `uninstall.php` | При удалении плагина удаляет настройку приоритетных ID. Товары, их дополнительные поля и страницы сохраняет. | Изменение правил очистки после удаления. |
| `README.md` | Эта инструкция для установщика и сопровождающего разработчика. | Обновление инструкции при изменении плагина. |

Обычное наполнение каталога выполняется в WooCommerce, без изменения файлов. Если меняете файлы плагина, сохраните копию правок: замена плагина новым ZIP может их перезаписать.

## 7. Проверка после установки

1. Откройте тестовую страницу без авторизации и убедитесь, что модели загрузились.
2. Нажмите «Добавить устройство», найдите модель, добавьте третью. Четвёртая не должна добавляться.
3. Уберите модель из сравнения и добавьте другую. Проверьте «Очистить выбор».
4. Сверьте цену, фото, наличие и характеристики с карточкой WooCommerce.
5. Откройте страницу на телефоне: окно выбора и характеристики должны помещаться по ширине.
6. Измените цену одного товара и обновите страницу: сравнение должно показать новое значение.

Для тестовой страницы на рабочем сайте задайте noindex через используемый SEO-плагин. Плагин сам не создаёт страницу и не назначает метку `_mcac_test_page` обычным страницам, созданным вручную.

## 8. Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| Модель не найдена в поиске | Публикацию товара и родителя вариации, отсутствие пароля, видимость каталога и атрибут алгоритма `SHA-256`. Убедитесь, что название введено без ошибки. |
| «Не указано» вместо характеристики | Значение и имя атрибута. Данные из текста описания или ACF автоматически не извлекаются. |
| Появляются не те две модели | Порядок ID в «Настройки → Сравнение ASIC». Используйте ID именно этого сайта; между сайтами ID различаются. |
| «Не удалось загрузить данные» | Доступность `/wp-json/mc-asic-compare/v1/products` на домене сайта. Этот адрес должен возвращать JSON, а не страницу входа, заглушку или ошибку. Проверьте ограничения REST API, защитные плагины и режим Coming soon. |
| Данные не обновляются | Кэш сервера, CDN и оптимизаторов. Исключите маршрут `/wp-json/mc-asic-compare/v1/products` из принудительного кэширования. |
| Кнопки не работают | JavaScript в браузере и настройки объединения/отложенной загрузки скриптов. При конфликте исключите `assets/compare.js` из оптимизации и очистите кэш. |
| Вместо сравнения отображается шорткод | Плагин активен, шорткод вставлен в предназначенный для него блок или виджет. |
| Сравнение недоступно | WooCommerce установлен и активирован. |

В первой версии API загружает весь подходящий каталог, а поиск выполняется в браузере. На большом каталоге проверьте скорость: при необходимости разработчик может добавить серверный поиск и постраничную загрузку.

## 9. Обновление и удаление

Перед обновлением сохраните резервную копию сайта и собственных правок файлов. Установите новый ZIP поверх существующего плагина средствами WordPress, затем очистите кэш и проверьте тестовую страницу. Сохранённые настройки и товары остаются в базе.

Деактивация отключает функциональность. При удалении плагина удаляется его настройка приоритетного списка, но товары, изображения, дополнительные поля и страницы остаются. Уберите шорткод со страниц, если блок больше не нужен.
